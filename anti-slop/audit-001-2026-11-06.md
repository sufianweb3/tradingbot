# Anti-Slop Audit 001

## Findings

### High Priority (Hard Gate Violations)

1. **R-02 (Copywriting)**: Document `<title>` and UI section headers use em dashes (`—`) instead of colons, commas, or parentheses (`<title>OI Sniper — Paper Trading Bot</title>`, `<h3>Signal — open interest</h3>`, `<h3>Signal — volume</h3>`, `<h3>Signal — price change</h3>`).
2. **R-02 (Copywriting)**: Form dropdown options and status notes use em dashes (`ROE — % of margin`, `Price — % of coin`, `No API key — scraping the public website`).
3. **R-02 (Copywriting)**: Tooltips, toast strings, and status labels in `public/app.js` contain em dashes (e.g. `Off — coins can re-enter immediately`, `Qualified for both Long and Short — skipped`).
4. **R-25 (Color Contrast)**: Secondary text color `--dim: #5d7088` on dark background `--bg: #070b11` yields ~3.6:1 contrast ratio, failing WCAG AA (4.5:1 minimum for normal text).
5. **R-32 (Keyboard Accessibility)**: Interactive buttons (`.btn`, `.tab`, `.mode-badge`) lack explicit `:focus-visible` outline rings for keyboard navigation.
6. **R-32 (Keyboard Accessibility)**: Connect Wizard and Onboarding modals do not close on pressing the `Escape` key.
7. **R-39 (Accessible Semantics & Interaction Affordances)**: Missing global base `cursor: pointer` definition for all interactive elements (`button, select, summary, a[href], label[for]`).
8. **R-39 (Accessible Semantics & Interaction Affordances)**: Modal close buttons (`.modal-close`) display `×` without an accessible `aria-label="Close dialog"`.
9. **R-39 (Accessible Semantics & Interaction Affordances)**: No `prefers-reduced-motion` media query declared to honor user motion reduction settings for animations and transitions.

### Medium Priority (Purpose-Gate Violations)

10. **R-01 (Color & Gradients)**: Multiple full-page radial gradient orbs stacked in `.bg-glow` (green, blue, violet) without a stated hierarchy or brand purpose.
11. **R-06 (Typography)**: Strategy panel subtitle hardcodes `<code>data/state.json</code>` which is inaccurate for the client-side browser runtime (persisted in IndexedDB).
12. **R-10 (Glassmorphism)**: Heavy backdrop blur (`backdrop-filter: blur(14px)`) applied concurrently to sticky topbar, modal backdrops, and table headers.
13. **R-09 (Badges)**: Status pills combine rounded pill shapes, borders, soft color backgrounds, and glowing dots simultaneously without clear semantic hierarchy.

### Low Priority (Quality Locks)

14. **R-08 (Button Arrows)**: Hardcoded `▶` arrow glyph inside start/toggle button lacks `aria-hidden="true"`.
15. **R-11 (Border Radius Consistency)**: Inconsistent border radius tokens across elements (mixing 6px, 12px, 14px, 16px, and 999px arbitrarily).
